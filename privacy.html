Политика конфиденциальности

Дата обновления: 28 июля 2026 года
Сайт является личным некоммерческим проектом. На Сайте нет рекламы, систем веб-аналитики, рекламного отслеживания, публичной регистрации пользователей и форм для отправки персональных данных владельцу.
Сайт публикуется через GitHub Pages и открывается по протоколу HTTPS. Несмотря на шифрование соединения, не передавайте через Сайт настоящие пароли, платёжные данные или другую чувствительную информацию: Сайт не предназначен для их приёма.

1. Общие положения

Настоящая Политика объясняет, какие сведения могут технически обрабатываться при посещении сайта Andrey30 (далее — Сайт), для каких целей это необходимо и какие меры применяются для защиты данных. Владельцем Сайта является Andrey30.

Политика составлена с учётом общих требований Федерального закона от 27 июля 2006 года № 152-ФЗ «О персональных данных» в той мере, в какой его положения применимы к работе Сайта.

Публичные страницы и файлы Сайта размещаются в общедоступном репозитории владельца и публикуются с помощью сервиса GitHub Pages. Стандартный адрес проекта находится в домене github.io. Передача страниц между GitHub Pages и браузером пользователя выполняется по протоколу HTTPS.

2. Назначение Сайта и отсутствие целевого сбора данных

Сайт содержит информационные страницы, калькуляторы, конвертеры, торговый дневник, часы торговых сессий, помощник входа в сделку и страницы, посвящённые автоспорту. Большинство вычислений выполняется непосредственно в браузере пользователя.

Сайт не предназначен для сбора имени, номера телефона, адреса электронной почты, почтового адреса, платёжных реквизитов или иных анкетных данных посетителей. Личные кабинеты, публичная регистрация и формы обратной связи отсутствуют.

Редактор результатов Формулы-1 хранится у владельца локально и не размещается в публичной части Сайта. Он сохраняет введённые владельцем спортивные результаты на его устройстве и формирует файл results.json. Владелец вручную загружает этот публичный файл в репозиторий GitHub. Автоматическая отправка данных из редактора на GitHub не выполняется.

3. Данные на устройстве пользователя

Отдельные страницы могут сохранять выбранный язык, тему оформления, введённые значения, результаты расчётов, настройки, планы и записи торгового дневника в localStorage, кэше браузера или других локальных механизмах хранения.

Эти данные остаются на устройстве пользователя и не передаются владельцу Сайта. Пользователь может удалить их средствами соответствующей страницы либо очистив данные Сайта в настройках браузера.

Страница Формулы-1 загружает публичный файл results.json из того же репозитория GitHub через GitHub Pages и, при необходимости, через домен raw.githubusercontent.com. Содержимое файла со спортивными результатами может временно сохраняться в браузере для отображения таблиц и начисления очков. Через эту функцию данные посетителя владельцу Сайта не отправляются.

4. Технические сведения при посещении

Для передачи страниц инфраструктура GitHub Pages технически обрабатывает сетевой запрос посетителя. Такой запрос может содержать:

  • IP-адрес устройства;
  • дату и время обращения;
  • адрес запрошенной страницы или файла;
  • тип браузера и операционной системы (User-Agent);
  • адрес страницы-источника перехода (Referer), если браузер его передаёт.

Согласно документации GitHub, при посещении сайта GitHub Pages IP-адрес посетителя регистрируется и хранится в целях безопасности независимо от наличия учётной записи GitHub. Условия и сроки такой обработки определяются GitHub.

Владелец не устанавливает отдельные системы аналитики, не формирует собственную базу посетителей и не использует технические сведения для рекламы или профилирования.

5. Внешние информационные сервисы

Для размещения Сайта и отображения актуальных справочных данных браузер пользователя может обращаться к сторонним сервисам, в том числе:

  • GitHub и GitHub Pages — размещение и передача публичных файлов Сайта;
  • raw.githubusercontent.com — резервная загрузка публичного файла результатов Формулы-1;
  • CoinGecko — сведения о курсах криптовалют;
  • jsDelivr Currency API и Currency API Pages — справочные курсы валют;
  • CBR XML Daily и сайт Банка России — официальные и справочные финансовые данные;
  • сервис ключевой ставки, размещённый на платформе Vercel.

При таком обращении внешний сервис может получить IP-адрес, User-Agent, время запроса и другие технические сведения о соединении. Эти сервисы действуют независимо и обрабатывают сведения по собственным правилам конфиденциальности.

6. Cookie, кэш и автономная работа

Публичные страницы Сайта не устанавливают рекламные, аналитические, маркетинговые или авторизационные cookie.

Некоторые страницы могут использовать localStorage, кэш браузера и Service Worker для сохранения настроек, ускорения загрузки и частичной автономной работы. Эти механизмы можно очистить в настройках браузера. Service Worker торгового дневника ограничен файлами самого дневника и не предназначен для перехвата других страниц Сайта.

7. Цели технической обработки

Технические сведения могут обрабатываться только для следующих целей:

  • передача и корректное отображение запрошенных страниц;
  • выполнение выбранных пользователем функций;
  • получение актуальных справочных данных от внешних сервисов;
  • диагностика ошибок и поддержание работоспособности;
  • предотвращение неправомерного доступа, злоупотреблений и сетевых атак.

Сайт не осуществляет профилирование посетителей, не использует их данные для рекламы и не принимает юридически значимых автоматизированных решений.

8. Передача сведений

Владелец Сайта не продаёт сведения о посетителях, не передаёт их рекламным сетям и не использует для рассылок.

Техническая передача GitHub и другим внешним сервисам происходит при обращении браузера к соответствующим ресурсам. Такие сервисы могут получить сведения, необходимые для установления соединения и ответа на запрос. Сведения также могут быть предоставлены уполномоченным органам, если такая обязанность прямо предусмотрена законом.

9. Хранение и удаление

  • данные в localStorage и кэше хранятся на устройстве пользователя до их удаления самим пользователем, очистки данных браузера или удаления соответствующей записи средствами страницы;
  • сроки хранения технических сведений GitHub и другими внешними сервисами определяются их собственными правилами и техническими процедурами;
  • публичные файлы проекта и история их изменений могут храниться в репозитории GitHub до удаления или изменения владельцем.

10. Права пользователя и управление данными

Данные, сохранённые в localStorage или кэше браузера, находятся только на устройстве пользователя. Владелец Сайта их не получает, не видит и не может удалить удалённо. Пользователь может самостоятельно удалить такие данные в настройках браузера.

На Сайте отсутствуют учётные записи, форма обратной связи и публичные контактные данные владельца. Через интерфейс Сайта не предусмотрена передача персональных данных владельцу.

11. Меры защиты и ограничения

Соединение с GitHub Pages защищается протоколом HTTPS. Владелец не размещает в публичном репозитории локальный административный редактор, пароли, платёжные сведения и иные конфиденциальные данные, а также ограничивает объём подключаемых внешних сервисов.

Ни один способ передачи или хранения информации не гарантирует абсолютную безопасность. Сайт не предназначен для передачи паролей, платёжных реквизитов, документов и других чувствительных сведений.

12. Изменение Политики

Политика может обновляться при изменении функций Сайта, площадки размещения, используемых внешних сервисов или порядка технической обработки сведений. Актуальная версия публикуется в файле privacy.html.

Если в будущем на Сайте появятся формы, учётные записи посетителей, серверное сохранение введённых посетителями данных, аналитика, реклама или публичная серверная административная часть, Политика должна быть пересмотрена до включения таких функций.
